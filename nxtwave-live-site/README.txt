NxtWave Campus Growth Kit — demo deployment

To publish: open https://app.netlify.com/drop and drag this ZIP (or the extracted folder) into the drop area.
The published page is a browser-local demo. Registration records remain in the visitor's browser and are not shared with you. It does not send real messages or accept real event bookings.

Before using with real students, add a shared backend, verification, privacy/consent handling, and confirmed event details.
